# Context map — the LEDGE

Пиксельный платформер 320×180, тайл 16px. Канон: `tmp/ledge-v19.html`.

## Точки входа

- `index.html` — DOM (canvas `#c`, меню, стик, кнопки, редактор)
- `src/main.js` — bootstrap
- `src/core/game.js` — фасад симуляции (бывший IIFE `GAME`)
- `src/app/loop.js` — rAF, камера, пауза, меню
- `src/ui/menu.js` — главное меню «Уступ» (New Game / Continue / Settings / Credits); список уровней — под Continue; заставка `src/ui/splash.js` зовёт `showMenu()`, не старый список

## Ядро

| Модуль | Суть |
|--------|------|
| `core/constants.js` | `T=16`, ids тайлов, физика `C` |
| `core/runtime.js` | `MAP_W/H`, `base` Uint8Array, `LV`, `W` |
| `core/map.js` | запросы тайлов, скосы (`SLOPE_SPEC`: 45°, 2:1, 4:1, дуги), `rectFree` |
| `core/player.js` | хват кромки, лаз, лестницы, перекладины, вода, авто-карабканье на уступ в 1 тайл (`tryMantle`) |
| `core/step.js` | один тик мира; на скосе `dx` режется на `SLOPE_ALONG/√2` (~90% бега вдоль склона) |
| `levels/` | 5 карт, `build()` пишет в `base` |
| `entities/` | mk/step врагов, лифтов, факелов, сундуков, щупалец, NPC |
| `entities/ids.js` | `findById` / `allocId` — двери и объекты по id, не по индексу |

Двери: `pair` / `doorId` / `warp.to` — это `id`, не индекс массива. Факел в руке — `p.torch` = id.

Финиш уровня рисует outro со статистикой: складка из героини как у инвентаря, кнопки REPLAY (тот же уровень сначала) и CONTINUE (следующий; на последнем — MENU, `next: -1`). Заставка с названием уровня — та же складка, тап/пробел сворачивает.

Прыжок с поверхности воды: `swimLaunch` только вверх; на входе/возврате — короткий нырок, потом быстрое всплытие (`SWIM_UP` сильнее `SWIM_DN`). Удержание вниз ныряет медленно. Гребок вверх не режется потолком скорости. В воде `apexY` не копится — всплытие не даёт урон как с падения. С поверхности к сухому берегу + направление — `tryClimbOut` (лаз или хват); под водой, по подводным полкам и у потолка (камни сразу над водой) не вылазиваемся — всплыли у потолка, там и остаёмся.

Уступ в 1 тайл при ходьбе — `tryMantle` → `startVault`, `p.climb.kind==='vault'`. Это только паркур на ступеньку выше (`findChestStep`: стенка в тайл на колене; земля под ней не нужна). Пропасть шире 1 тайла — не паркур и не авто-лаз. Если на уступе стоя не влезает — `tryEnterGap`: тот же паркур, стойка присед/лёжа (`bestLand`) после анимации. Щель у пола (`findFloorGap`) тоже паркур, не упор в губу; яма вниз — игрок жмёт ↓. Смена стоек по вводу ждёт `stanceT`. Авто-вставание (`gapCrawl`) — один раз в момент выхода из тоннеля, когда стоя уже влезает; внутри не поднимает. Из лёжа у края: яма больше тайла — вис, иначе скат. Из свисания лаз в стойку щели тоже после анимации. У открытого края ↓: присед → лёжа → вис; удержание ↓ (`C.EDGE_HOLD`) — сразу в вис, кроме хода от края (`awayFromEdge`).

Щупальца водорослей (`entities/tendrils.js`, `LV.tendrils: [col, row, kind]` или `[col, row, kind, side]`): корень на твёрдом тайле. `side` 0 пол↑, 1 потолок↓, 2 левая стена→, 3 правая стена← (без поля — пол). kind 0 тянется и жалит (−1 hp); kind 1 обвивает (`p.state==='snare'`), тащит к корню, держит `C.TEND_HOLD` (~2.6 с) и отпускает. Воздух на хвате тикается (`tickSnareAir`); вырваться — палкой, гарпуном или дёрганьем. Убийство палкой/гарпуном — в `stepTendrils` (`probeHarpoons`, цикл импорта через `harpoons.js` нельзя). Рисуются поверх героини (`tendrils()`).

Пауки (`entities/spiders.js`): если потолок над ними пропадает (хрупкий `CRUMB` в `S.gone`) — падают и убегают (`fall`/`flee`, без лута). Паутину на спуске можно порвать палкой или гарпуном — тот же срыв. Нить рисуется чередованием светлого/тёмного, не сплошной верёвкой.

Гарпун (`p.gear.harpoon`, рука `p.hand`): в воде — болт как лук (`fireHarpoon`, без подтяга, стрелы подбираются). На суше — крюк (`fireGrapple`): 45° вперёд, при удержании ↑ — строго вверх; длина `C.HARPOON_LEN`, тяга `C.HARPOON_PULL`, отстёгивается за `C.HARPOON_DETACH` и летит по импульсу+гравитации. Смена руки (палка/лук/гарпун): Q или тап по иконке оружия в HUD (`cycleHand`).

Подбор факела/палки (`tryAction` в `entities/torches.js`) — `tryAction` только ставит `p.pickPend`/`p.pickT`; фактический attach (`t.held`/`p.torch`/`giveGear`) делает `resolvePickup` (вызывается из `step.js` каждый кадр) на нижней точке приседа (доля `PICK_APEX=0.45`, синхронно с `render/poses.js:pickPose`). Бросок факела симметрично: `p.throwT`/`p.throwPend`, сам `dropTorch(S,true)` срабатывает в `resolvePickup` на доле `THROW_REL=0.4` (синхронно с `throwPose`). Ничего не блокирует управление — это оверлей позы поверх `state==='normal'`.

Стойка стоя/присед/лёжа: хитбокс в `setStance` сразу (физика), поза блендится `p.stanceT`/`p.stanceFrom` (`C.STANCE_T`). Следующий шаг по вводу — только когда `stanceT` кончился (удержание ↑ не перескакивает присед). Защитные вызовы (лифт, потолок, перекат) блендинг не запускают.

Падение: `fall > C.SAFE` без переката — `startFallRecover` в присед (`C.FALL_CROUCH_T`) или лёжа если `fall > C.HURT` (`C.FALL_PRONE_T`). `p.recoverSt` держит стойку, `state==='stun'` блокирует ввод; по таймеру `finishFallRecover` сама встаёт (или в присед, если потолок). Из лёжа хитбокс остаётся `stance===2`, пока играет `getupPose` (`p.gettingUp` / `getupT` = `C.GETUP_T`); `setStance(0)` только в `finishGetup`, когда поза доиграла — иначе корпус висит в воздухе. Иначе ещё `C.STANCE_T` без управления, потом контроль. Урон как раньше. `hp<=0` — `S.dead`, игра на паузе, затемнение и плашка «life capacity reached»; тап/любая клавиша — в меню (больше не `resetPlayer` на чекпоинт).

Взгляд вверх стоя на месте: `p.lookUp` (0..1, плавно) в `step.js`. Тело не меняет позу — поворачивается только сама голова вокруг основания черепа (`render/figure.js:drawHead`, угол `tilt` пробрасывается через `figure()`), коса по-прежнему свисает по своей физике (`wag`/`view.tail`), не завязана на поворот головы. Поворот пикселей головы считается в JS и округляется до целого пикселя (не через `ctx.rotate` — тот даёт субпиксельные прямоугольники и голова «мутнеет», не вписываясь в остальной чёткий пиксель-арт рендер). Камера уже давно приподнимается в этом случае (`wantLook` в `loop.js`) — только позы игроку не хватало.

Упор в стену: `p.pushWall` (в `step.js`, рядом с проверкой мантла в ветке `ax !== 0` при блокировке движения) — true только пока держат ввод в стену на земле в стойке; отпустили — сразу `false`, обычная стойка. Поза `WALLPUSH` (`render/hero.js:boxPose`) — ладони на уровне груди, чуть вверх по стене, не вытянуты вперёд.

Музыка: `src/audio/music.js` + каталог `src/audio/scores/` (`catalog.js`). Chip WebAudio, без MP3. Форма Sonic/Contra: `loopStart` после intro — интро один раз, луп A–B–C. Авторские: `moss-steps` / `mist-shelf` / `still-pool` / `ember-run` (`npm run music:compose`). Старый `lantern-key` из MP3 (`npm run music:score`). Mix: Play/Pause/Stop, seek, секции, `ledge.dev.score`. Старт в `startLevel`, hush на меню/паузе/редакторе/outro/dead/hidden. Пауза в Mix (`hold`) не снимается сама. Отладка `window.__music`.

Реплики: `src/speech/` — неблокирующие бабблы героини (`mutterHero`: empty / locked / first) и ветвящиеся диалоги NPC (`TREES` в `trees.js`, `startTalk` / `stepSpeech`). Баббл пиксельный (`render/bubbles.js`), хвост к говорящему, печать по буквам. Звук буквы — `audio/talk.js` (`talkBlip`, варианты в `TALK_VARIANTS`); выбранный тембр в `ledge.dev.talk`. Лаборатория: `/talk-lab.html`. Первый подбор каждого kind — `ledge.dev.seenKinds`. NPC: `LV.npcs: [[col,row,tree,facing,dialog?]]`, объекты редактора Hermit / Wanderer; клик по NPC открывает окно дерева (`editor/npc-talk.js`). Выбор ответа не меняет стойку/взгляд (во время `speechBlocks` ↑↓ не идут в позу). `breakTalk` если враг ударил героиню или напугал NPC — тот бежит домой/в дверь (`stepNpcs`) и прячется, пока враги не уйдут. После `told` повтор — короткий пул `already`, полный текст только если игрок попросит. Пустой сундук (`loot: []` или повторный action) и запертая дверь без ключа — mutter.

## Рендер

Процедурные пиксели (`rc`/`lb` + кэш `fillStyle`), кэш чанков 8×8. Свет — offscreen multiply; мерцание факела — альфа, не радиус. Позы героя — скелетные ключи. Волны воды — полоса на кадр, только на настоящей поверхности (не под камнем внутри воды). Озеро: `LV.water: [[col,row,shade],…]` — `shade` 0 чистая … 1.7 бездна, затемняет тайлы и героя по глубине от поверхности; в редакторе пресеты на кисти «вода». Брызги на верхних тайлах у берега (гребень волны). Пузырьки — разный размер и скорость. Передний план — offscreen по ширине карты. `torchPts` кэшируется на кадр. Камера — `clampCam` + мёртвая зона (`cam.ax/ay`, `loop.js`): цель камеры (`want`) следует не за игроком напрямую, а за якорем, который двигается только когда игрок выходит за 10×8px зону вокруг него; сама `cam.x/y` по-прежнему eased к цели каждый кадр. Приземление (`landdust`, `fall>6`) — мягкая пыль у ног, число/разлёт от высоты; удар головой о потолок в прыжке (`bonk` в `moveY`, `vy<-36`) — крошка вниз. Частицы `kind:'dust'` в `drawParts` (альфа, размер, drag).

## Ввод

После заставки — главное меню (New Game, Continue → карта уровней, Settings, Credits), не сразу список уровней. Клавиши + виртуальный стик слева (`#stick`) + ✋/⤒ справа. Q / тап по иконке оружия — смена руки (палка, лук, гарпун). I / тап по героине — инвентарь (`render/inventory.js`): панель 70% экрана, раскрывается из героини сначала по вертикали, потом по горизонтали; сворачивается в обратном порядке. Та же складка (`render/fold.js`) у окна названия уровня и окна статистики в конце. Табы ALL / FIND / GEAR / PART (`entities/catalog.js`). Сетка `bag`+`parts`+снаряжение, тап по слоту — карточка с большой иконкой, статами, описанием и кнопкой DROP. Если в стеке больше одного, DROP открывает модалку HOW MANY (− / +, с 1). Дроп сразу: каждый экземпляр летит в свою сторону, физика лута тикает и при открытом паке; на земле лут покачивается как `S.items` (`lootDrops`, фаза `ph`). Автоподбор с земли — только `coin` / `gem` / `shroom`; сундук по-прежнему кладёт лут сразу. Оружие, стрелы, факел, ключ с земли и прочее — ✋ с анимацией подбора (`tryGroundPickup`). Драг предмета на предмет — крафт (`entities/craft.js`: палка+камень=копьё) или сборка пазла (куски OR, пока не выйдет целый). Много слотов — тап-драг скролл без полосы. Указатель пака слушается на window capture, не на канве: прозрачный `#stick` / `#acts` не ест слоты и DROP. Стик и ✋/⤒ полностью прячутся (`body.hide-pad`) в паке, меню, паузе, заставке, outro/dead и редакторе. Esc закрывает карточку, потом пак; симуляция на паузе, музыка играет. Блипы на открытие/закрытие пака, карточки, таб, дроп и крафт. Dev: клавиши 1 оружие / 2 предметы / 3 еда / 4 броня / 5 куски (`giveInvKit`, `window.__inv.kit`). Полоска `#sys` (Edit/Pause/Menu/…) скрыта: Tab — редактор, Esc — меню (из подэкрана — назад на home, с home — resume), P — пауза, R — рестарт. Редактор — `#edbar` (TAB / ESC): закладки Tiles / Objects / Params / Intro / Gear / Mix, ресайз за верхнюю полосу. Плавающие окна (`src/editor/float.js`): таск за шапку или ПКМ, ресайз за SE-уголок, скролл СКМ/колесом, без полос; позиция и размер в `ledge.ed.float`. MMB — панорама, колесо — зум ступенями 25–400% (`snapEditCam`, `0` = 1:1), RMB — стёрка (тайлы и объекты), Ctrl+клик — пипетка (тайл/объект; у тайла с вариантами ещё меню); Ctrl+драг на тайловом слое — рамка выделения, перетаскивание блока, Delete стирает. Даблклик по тайлу — окно геометрии/параметров. PNG можно бросить в редактор (`src/tiles/tN.png` + `ledge.dev.tiles`, Bake пишет в `BAKED.tiles`). Overlay-тайлы пишутся в канал `deco` поверх `base` и не подменяют коллизию. `cover` — это комнаты (подмена тайлов снаружи), не декор. Долгое нажатие — стереть и дальше тянуть стёрку. Undo/Redo — Ctrl+Z / Ctrl+Y (`src/editor/history.js`). Клик по стопке объектов перебирает следующий. Backspace на слайдере/цвете/селекте — заводской дефолт. Карта растёт от origin в любую сторону (`runtime.ensureMap`). Объекты — иконки, Ctrl+колесо меняет размер превью. Кисти и объекты можно перетащить из палитры на канву. Params — слайдеры по `C` (live, localStorage `ledge.dev.C`). Intro — пул фраз заставки (`ledge.dev.intro`) и своя фраза уровня `LV.intro` (пусто = рандом из пула). Gear — ресурс прочности оружия по уровню (`LV.gearDurability`, 0 = unbreakable). Mix — живой микшер трека уровня и навигация по форме. New Level — пустая карта в `LEVELS`. Del Level / × в меню — удалить уровень (кроме последнего; встроенные помечаются `_gone` в `ledge.dev.levels`). ESC из игры — меню и пауза, ESC из меню — возврат в сессию. HUD/стики в `body.edit-mode` скрыты. Скосы: 45° (`SLR`/`SLL`), половинки 2:1 (`SLR2`+`SLR3` / `SLL2`+`SLL3`, стык на T/2), четверти 4:1 (`SLR4A…D`), дуги (`SLRCA`+`SLRCB`). Кисть скоса при протяжке подбирает угол по штриху; дуга/кочка — если путь идёт вверх и вниз. Повторный клик той же кистью по клетке — рандом из `variants` (у stone: `RNDA`/`RNDB`). Правки пишутся в `LV` + `localStorage` `ledge.dev.levels` (`src/core/persist.js`) и, пока крутится Vite, сами в `src/core/defaults.js` (`/__bake`, `src/core/bake-client.js`). `stop-and-build.bat` собирает этот снимок. На `file://` старый localStorage не перекрывает более новый Bake (`preferLocal` / `savedAt`). Persist пакует двери, лифты, платформы, тьму, валуны, палку и ключ — не только врагов/лут.

Помещения / cover (`src/core/rooms.js`): на collide-слое буфер `cover`/`coverVary` — вид клетки, пока героиня не стоит на ней. `0` = не в комнате, `255` (`COVER_AIR`) = лаз (снаружи пусто, членство есть). Связная 4-окрестность = одна комната; активна, если ноги на её клетке. `tileAt`/`layerTile` подменяют коллизию сразу; рисунок — всегда правда карты + оверлей cover с альфой `1−vis` (`C.ROOM_FADE`, smoothstep); оверлей +1 тайл вокруг комнаты, чтобы автокромка соседей не давала рамку. Объекты: `roomHide` по занятости (step), `roomA` по vis (draw). В редакторе (`roomsOn == null`) оверлея нет. Редактор: кнопка Cover, ЛКМ пишет cover (Empty = лаз), RMB стирает членство, Alt+драг штампует `base`→`cover`. Не слой-параллакс и не `dark` AABB.

Слои (`src/core/layers.js`, панель `#edLayers` как в Pixis: глаз / 🔒; соло — Ctrl+клик по глазу; драг строки — порядок): рисуем на выбранный слой; +/− слой; параллакс X/Y раздельно (у collision-слоя всегда 1); hue / saturation / brightness на каждый слой. Небо / холмы / кусты / пыльца — те же слои (`kind`: `sky`/`ridge`/`fore`/`pollen`), не хардкод в `sky()`/`fore()`. Тайловый слой может включить Repeat: штамп `wrapW×wrapH` (до 256) тайлится бесконечно (1×1 = заливка). `tileAt` для физики сливает слои с `collide`. Передние тайлы — после героя (`tilesFront`); кусты/пыльца — после света. Герой и объекты живут на collision-слое: соло другого слоя их прячет. Соло — только в редакторе. Geo (`G` / кнопка) — оверлей геометрии коллизий.

Кастом-тайлы (`src/core/tileset.js`, id 64–255): PNG + флаги в `ledge.dev.tiles` / Bake `BAKED.tiles` / `src/tiles/tN.png`. Overlay пишет `deco` поверх `base`, коллизия остаётся у грунта. Встроенные id 1–32 тоже можно перекрасить: `tileGfx` в `ledge.dev.tiles` подменяет картинку, коллизия остаётся в коде. Несколько кадров (`frames`) крутятся в игре. Окно `#edTileEdit`: пиксели (Paint/Erase/Pick) отдельно от хитбокса (Hit / Collision). Re-import и дроп на окно меняют картинку; полоса кадров — анимация.

Спрайты персонажей (`src/core/spriteset.js`, `ledge.dev.sprites`): героиня, враги, птицы, пауки, NPC. В палитре Tiles секция Sprites; даблклик по объекту с анимацией тоже открывает окно. У героини каждая анимация — отдельная строка кадров; клик грузит кадр в пиксельный редактор. Неправленный кадр в игре рисуется по-старому (скелет / rc); после Paint игра блитует этот кадр.

Новые объекты: Sound (flat / falloff), Light (цвет / сила / радиус), Volume (color correct + маски круг / град. V-H / инверт / от центра; рамка с хэндлами осей и поворотом за угол). Инспектор `#edInspect`.

- `CLAUDE.md` — короткий pointer → `AGENTS.md` (auto-load Claude Code); не дублировать правила.
- `agents/*.md` — **SoT субагентов**; `npm run sync:agents` → `.claude/agents/*` + `.grok/agents/*` (generated, не править вручную).
- Version: SemVer SoT = `package.json`. Bump: `npm run bump:patch|minor|major|dev|…`. Хук `scripts/check-version-bump-hook.mjs` блокирует `git commit` без bump.
- Git: агент коммитит **локально**. Пуш только по явной команде; иначе пользователь жмёт кнопку сам.
- Dev server: свой Vite на сессию, не шарить; после проверки убить свой PID и закрыть свою вкладку. Порт из stdout, не `:5173`.
- Token audit: `npm run token-audit` → `tmp/token-audit/`.
