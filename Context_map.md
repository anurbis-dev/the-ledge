# Context map — the LEDGE

Пиксельный платформер 320×180, тайл 16px. Канон: `tmp/ledge-v19.html`.

## Точки входа

- `index.html` — DOM (`#view` + canvas `#c` мир / `#h` HUD, меню, стик, кнопки, редактор)
- `src/main.js` — bootstrap
- `src/core/game.js` — фасад симуляции (бывший IIFE `GAME`)
- `src/app/loop.js` — rAF, пауза, меню; follow камеры зовёт `followCam`
- `src/render/camera.js` — `clampCam` / `resetCam` / `followCam` / `pushCamRender` / `popCamRender` / `applyCamPan` / `clearCamPan`
- `src/ui/menu.js` — главное меню «Уступ» (New Game / Continue / Settings / Credits); список уровней — под Continue; заставка `src/ui/splash.js` зовёт `showMenu()`, не старый список

## Ядро

| Модуль | Суть |
|--------|------|
| `core/constants.js` | `T=16`, ids тайлов, физика `C` |
| `core/runtime.js` | `MAP_W/H`, `base` Uint8Array, `LV`, `W` |
| `core/map.js` | запросы тайлов, скосы (`SLOPE_SPEC`: 45°, 2:1, 4:1, дуги), `rectFree` |
| `core/player.js` | хват кромки, лаз, лестницы, перекладины, вода; ступень +1 тайл — `tryMantle` только вперёд+↑ |
| `core/step.js` | один тик мира; на скосе `dx` режется на `SLOPE_ALONG/√2` (~90% бега вдоль склона) |
| `levels/` | 5 карт, `build()` пишет в `base` |
| `entities/` | mk/step врагов, лифтов (`lifts.js`), платформ (`plats.js`), факелов, сундуков, щупалец, канатов (`ropes.js`), FX-эмиттеров (`emitters.js` → `S.emitters` / `LV.emitters`), NPC |
| `entities/ids.js` | `findById` / `allocId` — двери и объекты по id, не по индексу |

Двери: `pair` / `doorId` / `warp.to` — это `id`, не индекс массива. Поля `need` (bag kind|null), `consume`, `locked=!!need`; редактор ставит пару за 2 клика (`mkDoorAt`). Факел в руке — `p.torch` = id.

Выходы уровня: `LV.exits: [{id,x,y,toId}]` (миграция с одиночного `LV.exit`; blank → `[]`). `tryExit` читает exits; `finishLevel` резолвит `warp.toId` → индекс `LEVELS` (`null`/не найден → MENU, `next: -1`). Финиш рисует outro со статистикой (складка из героини): REPLAY / CONTINUE. Заставка с названием уровня — та же складка, тап/пробел сворачивает.

Прыжок с поверхности воды: `swimLaunch` только вверх; на входе/возврате — короткий нырок, потом быстрое всплытие (`SWIM_UP` сильнее `SWIM_DN`). Удержание вниз ныряет медленно. Гребок вверх не режется потолком скорости. В воде `apexY` не копится — всплытие не даёт урон как с падения. С поверхности к сухому берегу + направление — `tryClimbOut` (лаз или хват); под водой, по подводным полкам и у потолка (камни сразу над водой) не вылазиваемся — всплыли у потолка, там и остаёмся.

Ступень +1 тайл: без ↑ — упор в стену; вперёд+↑ — `tryMantle` (анимация climb). Авто-паркура при ходьбе нет. Смена стоек по вводу ждёт `stanceT`. Авто-вставание (`gapCrawl`) — один раз в момент выхода из тоннеля, когда стоя уже влезает; внутри не поднимает. Из лёжа у края: яма больше тайла — вис, иначе скат. Из приседа ход с открытого края — слезание в вис (`tryCrawlEdge` → `tryDescend`). Присед + ход + ↓ — перекат (`rollT`), не лёжа и не слезание. Стоя ↓ без разбега — присед; с разбега (`vx>58`) — перекат как раньше. Из свисания лаз в стойку щели тоже после анимации. У открытого края стоя ↓: присед → лёжа → вис; удержание ↓ (`C.EDGE_HOLD`) — сразу в вис, кроме хода от края (`awayFromEdge`).

Щупальца водорослей (`entities/tendrils.js`, `LV.tendrils: [col, row, kind]` или `[col, row, kind, side]`): корень на твёрдом тайле. `side` 0 пол↑, 1 потолок↓, 2 левая стена→, 3 правая стена← (без поля — пол). kind 0 тянется и жалит (−1 hp); kind 1 обвивает (`p.state==='snare'`), тащит к корню, держит `C.TEND_HOLD` (~2.6 с) и отпускает. Воздух на хвате тикается (`tickSnareAir`); вырваться — палкой, гарпуном или дёрганьем. Убийство палкой/гарпуном — в `stepTendrils` (`probeHarpoons`, цикл импорта через `harpoons.js` нельзя). Рисуются поверх героини (`tendrils()`).

Пауки (`entities/spiders.js`): если потолок над ними пропадает (хрупкий `CRUMB` в `S.gone`) — падают и убегают (`fall`/`flee`, без лута). Паутину на спуске можно порвать палкой или гарпуном — тот же срыв. Нить рисуется чередованием светлого/тёмного, не сплошной верёвкой.

CRUMB (id=2): idle/crack drip и burst осыпания — `emitSand` (`render/sand-fx.js`, `SAND_DEF`); в `gone` тайл не рисуется (без rubble). Placeable `FX Sand` (`fx_sand`) — `entities/emitters.js` (`mkEmitters`/`stepEmitters`/`sampleEmitterPoint`/`packEmitter`); `EMIT_SHAPES` point|square|circle|line; поля `shape`/`shapeSize`/`shapeAngle` (дефолт point/16/0); спавн зерна внутри формы → `emitSand`.

Канаты (`entities/ropes.js`): `LV.ropes` / `S.ropes` — `{id, orient:'v'|'h', ax,ay,bx,by, segs, elasticity, swingForce, length(H), optional damping/wind/climbV/grabR}`; runtime — Verlet `nodes` (`mkRopes`/`mkRopeAt`, `rebuildRope`, `packRope`). Constraint: equality к rest; elast→`eff^2.2`, stretch=eff·0.85 (мягкая пружина, не hard clamp); soft=eff/(eff+0.28); rider load gaussian. В `full` (rider / near player) после каждой итерации constrain незакреплённые ноды выталкиваются из solid-тайлов (`solidAt`, `C.ROPE_COL_EPS`). Райдер: clamp `t` + упор боками/головой (`resolveRopeRiderPose`); спуск на землю/платформу → отцеп. H: `lengthExtra` (0=span); хорда в основном без rider. V: wobble+climbLock; анимы `ropeClimb`/`ropeSwing` (по умолч. ladder/ladderD, facing зеркалит swing). H: bars; ↓ отцеп. `C.ROPE_*`.

Платформы (`entities/plats.js`): `LV.plats` / `S.plats` — `normPlat` / `mkPlatAt` / `packPlat` / `stepPlats`. Параметры: `w,h,v`, путь `x0/x1/y0/y1` + `vert`, `pause0/pause1`, `travel` (`pingpong`|`oneway`), `loop` (`infinite`|`once`), `trigger` (`auto`|`ride`), `onLeave` (`continue`|`return`|`stop`). Палитра `plat_h`/`plat_v` (MARKER); Inspect + гизмо `move`/`platA`/`platB`. Хват края (`tryGrab`): plat-края раньше тайлов (иначе губа клетки под палубой даёт ~T смещение); `facing` = лицом к платформе (`-edgeSide`); `keepAx`/`keepUp` гасят удержанный ход/↑. На палубе `findDescend` только `findDescendPlat`; лаз вверх — `standBox` на палубу (не `bestLand`). Вис+plat в solid → `crush`. В воздухе поза/клип всегда `fall`.

Лифты (`entities/lifts.js`): `LV.lifts` / `S.lifts` — `normLift` / `mkLiftAt` / `packLift` / `syncLiftFloors` / `stepLifts`. Параметры: `w,hh,v,dwell`, `floors[]`, `homeIdx`, `travel`/`loop`, `trigger` (`call`|`auto`|`ride`), `onLeave` (`stay`|`return`). Палитра `lift` (MARKER); Inspect (+/− Floor) + гизмо `move`/`liftFloor`. Call-кнопки в `step.js` только при `trigger==='call'`.

Гарпун (`p.gear.harpoon`, рука `p.hand`): в воде — болт как лук (`fireHarpoon`, без подтяга, стрелы подбираются). На суше — крюк (`fireGrapple`): 45° вперёд, при удержании ↑ — строго вверх; длина `C.HARPOON_LEN`, тяга `C.HARPOON_PULL`, отстёгивается за `C.HARPOON_DETACH` и летит по импульсу+гравитации. Смена руки (палка/лук/гарпун): Q или тап по иконке оружия в HUD (`cycleHand`).

Подбор факела/палки (`tryAction` в `entities/torches.js`) — `tryAction` только ставит `p.pickPend`/`p.pickT`; фактический attach (`t.held`/`p.torch`/`giveGear`) делает `resolvePickup` (вызывается из `step.js` каждый кадр) на нижней точке приседа (доля `PICK_APEX=0.45`, синхронно с `render/poses.js:pickPose`). Бросок факела симметрично: `p.throwT`/`p.throwPend`, сам `dropTorch(S,true)` срабатывает в `resolvePickup` на доле `THROW_REL=0.4` (синхронно с `throwPose`). Ничего не блокирует управление — это оверлей позы поверх `state==='normal'`.

Стойка стоя/присед/лёжа: хитбокс в `setStance` сразу (физика), поза блендится `p.stanceT`/`p.stanceFrom` (`C.STANCE_T`). Следующий шаг по вводу — только когда `stanceT` кончился (удержание ↑ не перескакивает присед). Защитные вызовы (лифт, потолок, перекат) блендинг не запускают.

Падение: `fall > C.SAFE` без переката — `startFallRecover` в присед (`C.FALL_CROUCH_T`) или лёжа если `fall > C.HURT` (`C.FALL_PRONE_T`). Зажатое направление на приземлении — auto-roll (`rollland`); при `fall > C.ROLL_HURT` всё ещё `damage(1, C.ROLL_HURT_T)`. `p.recoverSt` держит стойку, `state==='stun'` блокирует ввод; по таймеру `finishFallRecover` сама встаёт (или в присед, если потолок). Из лёжа хитбокс остаётся `stance===2`, пока играет `getupPose` (`p.gettingUp` / `getupT` = `C.GETUP_T`); `setStance(0)` только в `finishGetup`, когда поза доиграла — иначе корпус висит в воздухе. Иначе ещё `C.STANCE_T` без управления, потом контроль. Урон как раньше. `hp<=0` — `S.dead`, игра на паузе, затемнение и плашка «life capacity reached»; тап/любая клавиша — в меню (больше не `resetPlayer` на чекпоинт). Dev: `9` / `GAME.toggleInvuln()` — полный иммунитет к `damage()` и hard-land knockdown (враги/падение/drown и т.п.).

Взгляд вверх стоя на месте: `p.lookUp` (0..1, плавно) в `step.js`. Тело не меняет позу — поворачивается только сама голова вокруг основания черепа (`render/figure.js:drawHead`, угол `tilt` пробрасывается через `figure()`), коса по-прежнему свисает по своей физике (`wag`/`view.tail`), не завязана на поворот головы. Поворот пикселей головы считается в JS и округляется до целого пикселя (не через `ctx.rotate` — тот даёт субпиксельные прямоугольники и голова «мутнеет», не вписываясь в остальной чёткий пиксель-арт рендер). Камера уже давно приподнимается в этом случае (`wantLook` в `followCam`, `render/camera.js`) — только позы игроку не хватало.

Упор в стену: `p.pushWall` (в `step.js`, ветка `ax !== 0` при блокировке движения) — true только пока держат ввод в стену на земле в стойке; отпустили — сразу `false`, обычная стойка. Поза `WALLPUSH` (`render/hero.js:boxPose`) — ладони на уровне груди, чуть вверх по стене, не вытянуты вперёд.

Музыка: `src/audio/music.js` + каталог `src/audio/scores/` (`catalog.js`). Chip WebAudio, без MP3. Форма Sonic/Contra: `loopStart` после intro — интро один раз, луп A–B–C. Авторские: `moss-steps` / `mist-shelf` / `still-pool` / `ember-run` (`npm run music:compose`). Старый `lantern-key` из MP3 (`npm run music:score`). Mix: Play/Pause/Stop, seek, секции, `ledge.dev.score`. Старт в `startLevel`, hush на меню/паузе/редакторе/outro/dead/hidden. Пауза в Mix (`hold`) не снимается сама. Отладка `window.__music`.

Реплики: `src/speech/` — неблокирующие бабблы героини (`mutterHero`: empty / locked / first) и ветвящиеся диалоги NPC (`TREES` в `trees.js`, `startTalk` / `stepSpeech`). Баббл пиксельный (`render/bubbles.js`), хвост к говорящему, печать по буквам. Звук буквы — `audio/talk.js` (`talkBlip`, варианты в `TALK_VARIANTS`); выбранный тембр в `ledge.dev.talk`. Лаборатория: `/talk-lab.html`. Первый подбор каждого kind — `ledge.dev.seenKinds`. NPC: `LV.npcs: [[col,row,tree,facing,dialog?]]`, объекты редактора Hermit / Wanderer; клик по NPC открывает окно дерева (`editor/npc-talk.js`). Выбор ответа не меняет стойку/взгляд (во время `speechBlocks` ↑↓ не идут в позу). `breakTalk` если враг ударил героиню или напугал NPC — тот бежит домой/в дверь (`stepNpcs`) и прячется, пока враги не уйдут. После `told` повтор — короткий пул `already`, полный текст только если игрок попросит. Пустой сундук (`loot: []` или повторный action) и запертая дверь без ключа — mutter.

## Рендер

Процедурные пиксели (`rc`/`lb` + кэш `fillStyle`), кэш чанков 8×8. Свет — offscreen multiply; мерцание факела — альфа, не радиус. Позы героя — скелетные ключи. Волны воды — полоса на кадр, только на настоящей поверхности (не под камнем внутри воды); `paintWaveSpan` непрерывен по world X. Базовый travel постоянен: `tileGfx[13].shift` (−100…100, дефолт 100 = канон 2.2 вправо; 0 = стоячая база) — без spatially-varying фазы (она рвала гребень). Wave X (дефолт 50) — амплитуда/bob. FALL сверху/с края даёт energy+dist (`fallFieldAt`, D≈12): boost амплитуды и расходящаяся рябь `sin(k·|x−src|−ωt)`, не ломая базовую фазу. FALL-струи: `tileGfx[14].speed` (`getTileSpeed`, дефолт 70; Details Speed). Озеро: `LV.water: [[col,row,shade],…]` — `shade` 0 чистая … 1.7 бездна, затемняет тайлы и героя по глубине от поверхности; в редакторе пресеты на кисти «вода». Брызги на верхних тайлах у берега (гребень волны). Пузырьки — разный размер и скорость. Передний план — offscreen по ширине карты. `torchPts` кэшируется на кадр. Камера — `render/camera.js`: `clampCam` + якорь `cam.ax/ay` (`C.CAM_DZ_X/Y`, дефолт 10×8px) — `want` не за игроком напрямую, а за якорем; lead/look на `C.CAM_LEAD*` / `C.CAM_LOOK*`; резина `followCam` (`kk=1-exp(-CAM_FOLLOW*dt)`, дефолт 6.5), `CAM_SNAP` 1px липнет к цели. `pushCamRender` при `C.CAM_SUBPX` (дефолт 1): мир на `#c` буфер 321×181 (`BUF_W/H`, light buffer тоже +1) в `floor(cam+shake)`, доля — CSS `translate` `#c` на `round(frac * viewCss / 320)` внутри overflow:hidden `#view` (шаг экрана, не субпиксельный blit тайлов). HUD/vignette/fade/intro/outro/inventory/pause/dead на втором канве `#h` (320×180), без translate. Редактор и `CAM_SUBPX=0` — старый `Math.round(cam)`. `clientToGame` — rect `#view`. Ключи в Params → Camera, persist `ledge.dev.C`. `resetCam` на старте уровня обнуляет lead/look. Приземление (`landdust`, `fall>6`) — мягкая пыль у ног, число/разлёт от высоты; удар головой о потолок в прыжке (`bonk` в `moveY`, `vy<-36`) — крошка вниз. Песок/пыль: `emitSand`/`SAND_DEF` (`sand-fx.js`, реэкспорт fx/index) + `landDust`/`bonkDust`; частицы `kind:'dust'` в `drawParts` (альфа, размер, drag).

## Ввод

После заставки — главное меню (New Game, Continue → карта уровней, Settings, Credits), не сразу список уровней. Клавиши + виртуальный стик слева (`#stick`) + ✋/⤒ справа. Q / тап по иконке оружия — смена руки (палка, лук, гарпун). I / тап по героине — инвентарь (`render/inventory.js`): панель 70% экрана, раскрывается из героини сначала по вертикали, потом по горизонтали; сворачивается в обратном порядке. Та же складка (`render/fold.js`) у окна названия уровня и окна статистики в конце. Табы ALL / FIND / GEAR / PART (`entities/catalog.js`). Сетка `bag`+`parts`+снаряжение, тап по слоту — карточка с большой иконкой, статами, описанием и кнопкой DROP. Если в стеке больше одного, DROP открывает модалку HOW MANY (− / +, с 1). Дроп сразу: каждый экземпляр летит в свою сторону, физика лута тикает и при открытом паке; на земле лут покачивается как `S.items` (`lootDrops`, фаза `ph`). Автоподбор с земли — только `coin` / `gem` / `shroom`; сундук по-прежнему кладёт лут сразу. Оружие, стрелы, факел, ключ с земли и прочее — ✋ с анимацией подбора (`tryGroundPickup`). Драг предмета на предмет — крафт (`entities/craft.js`: палка+камень=копьё) или сборка пазла (куски OR, пока не выйдет целый). Много слотов — тап-драг скролл без полосы. Указатель пака слушается на window capture, не на канве: прозрачный `#stick` / `#acts` не ест слоты и DROP. Стик и ✋/⤒ полностью прячутся (`body.hide-pad`) в паке, меню, паузе, заставке, outro/dead и редакторе. Esc закрывает карточку, потом пак; симуляция на паузе, музыка играет. Блипы на открытие/закрытие пака, карточки, таб, дроп и крафт. Dev: клавиши 1 оружие / 2 предметы / 3 еда / 4 броня / 5 куски (`giveInvKit`, `window.__inv.kit`). Полоска `#sys` (Edit/Pause/Menu/…) скрыта: Tab — редактор, Esc — меню (из подэкрана — назад на home, с home — resume), P — пауза, R — рестарт. Редактор — `#edbar` (TAB / ESC): закладки Tiles / Objects / Params / Intro / Gear / Mix, ресайз за верхнюю полосу. Полосы скролла скрыты; СКМ-драг по `#edbar` панорамирует как у float (`bindMiddleScroll`). Плавающие окна (`src/editor/float.js`): таск за шапку или ПКМ, ресайз за SE-уголок, скролл СКМ/колесом, без полос; позиция и размер в `ledge.ed.float`. MMB на канве — панорама камеры, колесо — зум ступенями 25–400% (`snapEditCam`, `0` = 1:1), RMB — стёрка (тайлы и объекты), Ctrl+клик — пипетка (тайл/объект; у тайла с вариантами ещё меню); Ctrl+драг на тайловом слое — рамка выделения, перетаскивание блока, Delete стирает. Даблклик по тайлу — окно геометрии/параметров. PNG можно бросить в редактор (`src/tiles/tN.png` + `ledge.dev.tiles`, Bake пишет в `BAKED.tiles`). Overlay-тайлы пишутся в канал `deco` поверх `base` и не подменяют коллизию. `cover` — это комнаты (подмена тайлов снаружи), не декор. Долгое нажатие — стереть и дальше тянуть стёрку. Undo/Redo — Ctrl+Z / Ctrl+Y (`src/editor/history.js`). Ctrl+D — дубль кисти: Tiles → кастом-тайл; Objects → custom kind (`ledge.dev.objects`) + клон sprite def (`ledge.dev.sprites`) при наличии (не map-sel). Delete/Backspace на кастом-кисти Tiles (без map-sel) или Delete в `#edTileEdit` — `deleteCustomTileById` (скан всех уровней через `findLevelsUsingTile` live+`_stash`, confirm, `wipeTileIdEverywhere` + `removeTile` + `flushAllLevelsStore`). Клик по стопке объектов перебирает следующий. Backspace на слайдере/цвете/селекте — заводской дефолт. Карта растёт от origin в любую сторону (`runtime.ensureMap`). Объекты — иконки, Ctrl+колесо или Ctrl+ПКМ-драг меняет размер превью. Кисти и объекты можно перетащить из палитры на канву. Params — слайдеры по `C` (live, localStorage `ledge.dev.C`). Intro — пул фраз заставки (`ledge.dev.intro`) и своя фраза уровня `LV.intro` (пусто = рандом из пула). Gear — ресурс прочности оружия по уровню (`LV.gearDurability`, 0 = unbreakable). Mix — живой микшер трека уровня и навигация по форме. New Level — пустая карта в `LEVELS`. Del Level / × в меню — удалить уровень (кроме последнего; встроенные помечаются `_gone` в `ledge.dev.levels`). ESC из игры — меню и пауза, ESC из меню — возврат в сессию. HUD/стики в `body.edit-mode` скрыты. Скосы: 45° (`SLR`/`SLL`), половинки 2:1 (`SLR2`+`SLR3` / `SLL2`+`SLL3`, стык на T/2), четверти 4:1 (`SLR4A…D`), дуги (`SLRCA`+`SLRCB`). Кисть скоса при протяжке подбирает угол по штриху; дуга/кочка — если путь идёт вверх и вниз. Повторный клик той же кистью по клетке — рандом из `variants` (у stone: `RNDA`/`RNDB`). Правки пишутся в `LV` + `localStorage` `ledge.dev.levels` (`src/core/persist.js`) и, пока крутится Vite, сами в `src/core/defaults.js` (`/__bake`, `src/core/bake-client.js`). `stop-and-build.bat` собирает этот снимок. На `file://` старый localStorage не перекрывает более новый Bake (`preferLocal` / `savedAt`). Persist пакует двери, лифты, платформы, тьму, валуны, канаты (`ropes`/`packRope`), эмиттеры (`emitters`/`packEmitter`), палку и ключ — не только врагов/лут.

Помещения / cover (`src/core/rooms.js`): на collide-слое буфер `cover`/`coverVary` — вид клетки, пока героиня не стоит на ней. `0` = не в комнате, `255` (`COVER_AIR`) = лаз (снаружи пусто, членство есть). Связная 4-окрестность = одна комната; активна, если ноги на её клетке. `tileAt`/`layerTile` подменяют коллизию сразу; рисунок — всегда правда карты + оверлей cover с альфой `1−vis` (`C.ROOM_FADE`, smoothstep); оверлей +1 тайл вокруг комнаты, чтобы автокромка соседей не давала рамку. Объекты: `roomHide` по занятости (step), `roomA` по vis (draw). В редакторе (`roomsOn == null`) оверлея нет. Редактор: кнопка Cover, ЛКМ пишет cover (Empty = лаз), RMB стирает членство, Alt+драг штампует `base`→`cover`. Не слой-параллакс и не `dark` AABB.

Слои (`src/core/layers.js`, панель `#edLayers` как в Pixis: глаз / 🔒; соло — Ctrl+клик по глазу; драг строки — порядок): рисуем на выбранный слой; +/− слой; параллакс X/Y раздельно (у collision-слоя всегда 1); hue / saturation / brightness на каждый слой. На тайловом слое ещё per-cell `tint`+`grades` (кисть Color рядом с Cover: hue/sat/brightness/contrast без новых вариантов тайла; wrap — `stampTint`; рисунок — `paintGraded` CSS filter; persist пакует `tint`/`stampTint` как vary, `grades` — массив объектов). Небо / холмы / кусты / пыльца — те же слои (`kind`: `sky`/`ridge`/`fore`/`pollen`), не хардкод в `sky()`/`fore()`. Тайловый слой может включить Repeat: штамп `wrapW×wrapH` (до 256) тайлится бесконечно (1×1 = заливка). `tileAt` для физики сливает слои с `collide`. Передние тайлы — после героя (`tilesFront`); кусты/пыльца — после света. Герой и объекты живут на collision-слое: соло другого слоя их прячет. Соло — только в редакторе. Geo (`G` / кнопка) — оверлей геометрии коллизий.

Кастом-тайлы (`src/core/tileset.js`, id 64–255): флаги + опционально `spriteId` / legacy PNG в `ledge.dev.tiles` / Bake `BAKED.tiles` / `src/tiles/tN.png`. Overlay → `deco` поверх `base`. Builtins 1–32: `tileGfx` (картинка и/или `spriteId`); FALL — `speed`, WATER — `shift`/`waveX`. Resolve: `getTileSpriteId` / `tileFrameSrc` / `tileImage` предпочитают idle (или первый anim) спрайта; иначе legacy `src`/`frames`. `#edTileEdit` для тайла (`fillTileParamsOnly`): слот **Sprite** (`setTileSpriteId`; Clear/Edit/dblclick → `openSpriteEdit`) + collision/flags — без Paint/Re-import/Reset picture (`canPaint()` только sprite-mode). Boot: `migrateEditorGraphics` (`src/editor/migrate-graphics.js`) — `migrateTilePicturesToSprites` + `ensureCatalogIconFrames`. PNG-drop / Ctrl+D на Tiles → сразу `migrateTilePicture`. Удаление кастома — Delete в окне или на кисти Tiles: wipe id на всех уровнях → `removeTile` + persist.

Вкладка **Tiles** — кисти карты (built-in + custom). **Sprites** (`data-tab=sprite`) — `listSpriteDefs()`; единственное место Paint; даблклик → `openSpriteEdit`; драг `{ spriteId }` на Tile/Object Sprite slot / frame thumbs; drop PNG → `addSpriteDef`; Ctrl+D → `cloneSpriteDef`; Delete custom → clear refs (tiles/objects/spawn) → `removeSpriteDef`; hint «Atlases — soon». **Objects** — `ED_OBJS` (`objectset.js`). Details `#edTileEdit`: даблклик Tiles/Sprites/Objects; одиночный клик переключает цель. Objects всегда `openObjectEdit` (params + Sprite slot; не редирект в Paint) — Hero/Light/foes тоже; Edit/dblclick слота → `openSpriteEdit`. Object Sprite slot — предпочтительно Sprites tab (не создаёт sprite из Tiles `tileSrc`/`makeTile` на слоте). Role: `actor|pickup|loot|prop|marker`. Ctrl+D Objects: клон kind; каталог → `cloneSpriteDef`; процедурка → bake `addTile`+`addSpriteDef`. `Start` — `spawn.spriteId` → `activeHeroId()`. Entities могут нести `spriteId`. Thumbs: `spriteThumb`; `tileThumb` учитывает `spriteId`. Undo/Redo — карта + tileset/spriteset/objectset (+ spawn).

Спрайты (`src/core/spriteset.js`, `ledge.dev.sprites`): `SPRITE_DEFS` = персонажи (hero / enemy* / flier* / spider* / npc_*) + placeable object icons (coin/chest/door/torch/gear/markers/…); кастом-клоны. Каталог/импорт/Paint — вкладка Sprites; кадры из Objects/Tiles Details — через Edit слота → `openSpriteEdit`. Boot icon-каталог (не characters): `ensureCatalogIconFrames` печёт `paintObjIcon` в dirty idle. У `enemy*`/`flier*`/`spider*` открытие sprite-edit материализует bake во все слоты. Полоса: `+` / драг-reorder / Play/Stop. Якоря: origin / Box / Hands / weapon. Size — `fw×fh`. Origin/box/Hands → Bake `BAKED.sprites` (без PNG); кадры — localStorage. Bake/thumb без dirty: `paintObjIcon(def.kind)`; hero-family — `isHeroSprite` + `bakeHeroFrame(id)`. Плавающие окна и `#edbar` без полос: панорама СКМ-драгом.
