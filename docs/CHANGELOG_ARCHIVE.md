## 0.1.0-dev.6

- С поверхности воды к краю + направление — забирается (`tryClimbOut`); под водой кромки не хватает.
- Из свисания лаз сразу в стойку щели: стоя / присед / ползок (`bestLand`).
- Подбор факела/палки: предмет атачится к руке на кадре нижней точки приседа (`resolvePickup`).
- Бросок факела: анимация замаха, факел улетает на ~40% анимации.
- Упор в стену — поза `WALLPUSH`.
- Плавный переход стоя/присед/лёжа (`p.stanceT`).
- Взгляд вверх на месте (`p.lookUp`, `LOOKUP_A`).
- Камера: мёртвая зона `cam.ax/ay` 10×8px.

## 0.1.0-dev.5

- Всплытие больше не бьёт головой о поверхность: в воде сбрасывается `apexY`, у поверхности режется скорость вверх, хват кромок в воде выключен.

## 0.1.0-dev.4

- Вход в воду и возврат после выпрыгивания: короткий нырок (~14px), без резкого стопа на поверхности.

## 0.1.0-dev.3

- `rc`/`lb` не ставят `fillStyle`, если цвет тот же (`setFill`).
- Мерцание факелов: фиксированный радиус, пульс альфы.
- Полоса волн воды собирается раз на кадр и блитуется на поверхность.
- Три слоя переднего плана — offscreen на ширину карты, пыльца по-прежнему живая.
- Камера и пан редактора через `clampCam`; `spark` реэкспорт фасада рендера.
- Авто-карабканье на уступ в 1 тайл при ходьбе (без прыжка): переиспользует анимацию `climb`, не роняет факел в руке.
- Нырок после прыжка с поверхности: `swimLaunch` только вверх, на падении вода сразу гасит скорость.

## 0.1.0-dev.2

- Двери и варп ищутся по `id`, не по индексу массива (N7).
- Финиш 5-го уровня больше не глотает outro меню (N8).
- Рыбы живут в своём водоёме, а не по всей воде уровня (N9).
- Перекат без `inp.x` не разворачивает лицом влево (N10).
- Приземление вброд / в воду не даёт урон от падения (N11).
- Стабильные id сущностей: `allocId` / `findById`, факел в руке хранит id (P8).
- Перф: волны только на поверхности воды, кэш `torchPts` на кадр, Y-отсечение водорослей, `buildWater` только при смене воды.

## 0.1.0-dev.0

- Ревизия ledge-v19: ES-модули + Vite single-file (`npm run build` → `dist/index.html`).
- Фасад `GAME`, 5 уровней, хуки `__state`/`__start`/`__game`.
- Фикс: `dropTorch` без факела не роняет цикл; `resetPlayer` снимает `held`.
- Фикс: точечный `invalidateChunk` (соседи 3×3), `hardReset` сбрасывает кэш.
- Фикс: `AudioContext.resume`, пауза на `visibilitychange`, пила лифта глушится.
- Фикс: скос LADR совпадает с физикой; LIGHTS только у ур.1 / `LV.lights`.
- Фикс: `R` в textarea экспорта не сбрасывает уровень; укус рыбы через `damage`.
