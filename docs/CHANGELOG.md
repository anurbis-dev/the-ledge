# Changelog (unreleased)

- Feat(core,entities,render): автомобиль (транспорт, vehicle mount) — расширены аним-слоты (turn, block, action1, action2), стойка за рулём гейтится по наличию аним у скина (crouch/prone не доступны без кадров), разворот вместо мгновенного флипа (если есть 'turn' anim), новые множители jumpMul (прыжок) и wallSlideMul (слайд стены), редактор: слайдеры Jump и Wall slide в окне Vehicle. Bug fix: speedMul теперь применяется в игре (раньше редактор читал, но ход игрока его игнорировал).
- Feat(core,render): ↓ за рулём транспорта без 'crouch' anim, но с 'block' — включает `p.mountBlocking` (поза 'block' вместо приседа, стойка/хитбокс героини не трогаются); action1/action2 пока не замаплены ни на один ввод.
- Fix(editor): окно Vehicle-параметров (и Hero Move Settings) не перетаскивалось за шапку/ПКМ и не резайзилось — `bindAllFloats()` (editor/float.js) навешивает drag/resize только на захардкоженный список id, `edVehicleSettings`/`edHeroMoveSettings` в нём не было, хотя разметка и код окна (`ed-float`, `placeFloat`/`raiseFloat`) были такие же, как у Boulder/Rope. Добавлены оба id в список.
- Fix(core): разворот транспорта (`stepMountTurn`) переделан с "играть, пока держат противоположную сторону" на edge-триггер — сама смена желаемого направления один раз запускает scrub, дальше он доигрывает автоматически по dt каждый кадр независимо от того, держит ли игрок клавишу; передумать (нажать исходное направление ещё раз) тоже edge, крутит те же кадры назад с текущего места. Заодно пока `p.turning` — блокируются прыжок (обычный и wall-jump), block, атака (`entities/enemies.js:attack`) и высадка (`tryDismount`), не только ускорение в новую сторону.
- Fix(core): окно высадки (0.25с unmount-анимации после `tryDismount`, пока транспорт ещё виден на экране) не блокировало ввод — `p.mount` уже null, поэтому герой мог тут же побежать/прыгнуть/атаковать/сесть обратно, пока визуально всё ещё стоял на месте транспорта. `core/step.js` теперь зануляет весь ввод на это окно (тем же паттерном, что у `talking`), плюс сбрасывает буфер прыжка.
