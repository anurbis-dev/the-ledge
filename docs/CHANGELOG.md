# Changelog (unreleased)

- Refactor(sprites): убран множитель разрешения арта (`res`, `setSpriteRes`, поле "Res" в редакторе спрайтов) — был источником рассинхрона плотности пикселей героини/спрайтов с тайлами. Холст редактора и импорт картинки теперь всегда строго `fw×fh` (1 арт-пиксель = 1 мировой пиксель); импорт одиночной картинки любого размера масштабируется целиком в `fw×fh`, лист кратный `fw×fh` по-прежнему режется по сетке. Поле Size (`fw`/`fh`, физический размер/хитбокс) не тронуто.
