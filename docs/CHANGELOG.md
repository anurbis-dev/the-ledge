# Changelog (unreleased)

- Fix(gameplay/editor): угол Rot удерживаемого предмета (`weapon.rot` в Object Details) не зеркалился по facing героини — при взгляде влево наклон/поворот арта оставался таким же, как вправо, вместо противоположного. `blitHeldSprite` (`render/sprites.js`) получил параметр `facing` и инвертирует `weapon.rot` при `facing < 0`; вызовы из `drawTorches` (держит факел — `S.p.facing`, на земле/в полёте — без зеркалирования) и `hero.js:overlayHeroWeapon` (оружие в руке) обновлены.
- Refactor(render): масштаб канваса (`RENDER_SCALE`×`viewScale`) был раскидан вручную по ~10 местам (`ctx.setTransform` в `loop.js`/`editor.js`, raw-pixel формулы в `hero.js`/`volumes.js`, свой копипаст создания offscreen-канвы в каждом тайловом кэше) — именно поэтому предыдущие два фикса (chunk-кэш тайлов, `viewportRev`) чинили баги по одному, а не структурно. Сведено к общим примитивам в `render/ctx.js`: `deviceScale()`/`applyWorldTransform()` (единая точка выставления трансформации, 9 call-сайтов в `loop.js`/`editor.js` теперь не могут забыть про `RENDER_SCALE`), `makeBakeCanvas`/`blitBake` (общая фабрика offscreen-кэша, теперь используется и `chunkOf`/`stampOf`/`coverCanOf`/`tintScratch`, и HUD-панелями), `onViewportChange(fn)` — push-подписка на смену вьюпорта вместо ручного опроса счётчика `viewportRev` (убран).
- Fix(render): попутно найдены и исправлены ещё 2 места того же класса бага, не пойманные в прошлый раз — кэш волн воды (`wStrip`/`reuseCan`/`blitWaves` в `tiles.js`) и HUD-панели intro/outro/inventory (`introCv`/`outroCv`/`invCv`, `fold.js:foldBlit` теперь берёт src-rect из реального размера canvas, а не логического) — все три пеклись в нативном разрешении, детализация терялась до отрисовки. `fx.js`: sky/vignette градиенты (`fillSky`/`vignette`) больше не кэшируются — дешёвые, пересоздаются каждый вызов, инвалидировать нечего. `inventory.js` теперь подписан на `onViewportChange` — геометрия панели обновляется сразу при ресайзе окна, даже если инвентарь уже открыт (раньше — только при следующем открытии).
