# Changelog (unreleased)

- Feat(gameplay/editor): собственный якорь предмета (`weapon` в Object Details, per-objectKind, тот же ключ что и у героини) теперь реально работает для удерживаемых предметов — новый `blitHeldSprite` (`render/sprites.js`) рисует спрайт, привязанный к `objectKind` (`torch`, `sword`, `pickaxe`…), так, чтобы его собственная grip-точка совпала с якорем руки героини; поворот (замах/копка/бросок) — вокруг этой же точки. Пока для kind нет спрайта — рисуется как раньше, процедурно (fallback не тронут). Позволяет вручную указать точное место ручки топора/факела на арте, когда он появится.
- Fix(gameplay): факел в руке героини теперь привязан к якорю кисти (`hF` из `render/poses.js` через новый `heroWeaponWorld` в `core/sprite-grab.js`) для всех анимаций, а не только к грубому смещению по стойке (стоя/присед/лёжа) — рука с факелом корректно следует за позой при атаке, копке, броске, лестнице и т.д.
- Fix(editor): импорт одиночной картинки в новый спрайт (`importSpriteFiles`, Sprites-таб, drag&drop) больше не режет её по умолчанию на грид 16×16 (`sliceSheet(img, name)` без `cellW/cellH`) — любая картинка крупнее одной ячейки (32×32, 48×48…) тихо превращалась в 4+ отдельных кадра-осколка вместо одного цельного спрайта. Теперь один файл = один спрайт нативного разрешения (`fw/fh` = размер картинки, клампится 8–128), без нарезки. Импорт тайлового листа (Tile-таб) не тронут — там нарезка по гриду 16×16 осталась целевым поведением.
