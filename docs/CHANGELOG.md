# Changelog (unreleased)

- Fix(render): отладочный оверлей коллизии (Geo overlay, клавиша G) для V-flip скосов теперь рисует заливку (визуализацию solid-зоны) на правильной стороне тайла. Раньше якорь заливки всегда был внизу (`y+T`), даже когда физика считала solid-зону сверху для потолочной ориентации.
- Fix(physics): убрана асимметрия коллизии скосов между обычной и V-flip ориентацией. Обе ориентации теперь блокируют AABB по своей гарантированно-сплошной грани (новая функция `slopeBlocks` в `core/map.js` вместо `ceilSlopeBlocks`). `groundYAt` приземляет игрока на плоский верх V-flip скоса; `ceilYAt` останавливает движение вверх о плоский низ обычного скоса; `pixSolid` (поиск уступа для ledge-grab) игнорирует скосы.
- Refactor(editor): удалена адаптивная покраска скосов кистью (удалён `src/editor/slopes.js`). Раньше при рисовании скоса штрихом редактор автоматически подбирал вариант id по форме росчерка и соседям (детект холма/ямы/рампы). Теперь скос красится как обычный тайл — ставится ровно тот id, что выбран в палитре, без автоподбора.
