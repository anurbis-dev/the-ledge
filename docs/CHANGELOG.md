# Changelog (unreleased)

- Feat(editor): per-level `camZoom` поле (25–400%, дефолт 100) — зум камеры уровня в редакторе (вкладка Intro, слайдер Camera zoom). Масштабирует FOV (видимый мир на экране) в геймплее; редактор неподвижен на 320×180.
- Fix(render): `blitEntSprite`/`blitHeroSprite`/`blitHeldSprite` больше не растягивают native-разрешение кадра в footprint (fw×fh) по двум осям независимо — теперь единый масштаб (`fitFrame`, src/render/sprites.js), fw×fh остаётся верхней границей блита без искажения квадратности арт-пикселей.
- Fix(editor): превью Sprite/Object Details (src/editor/tile-edit.js) и превью кадров в анимационных полосках больше не растягивают арт по двум осям независимо при несовпадении аспекта art-буфера и footprint — теперь тот же `fitFrame`, что и в рендере (леттербокс вместо искажения).
- Feat(editor): зум колесом мыши над окном превью Sprite/Object Details (50–800%), не мешает скроллу остальной панели.
- Feat(editor): в Object Details (hitbox-инструмент) красную рамку box теперь можно тащить за любую сторону/угол — ресайз с фиксированным противоположным краем, а не только "нарисовать заново" из угла.
- Feat(editor): удаление кадра анимации клик-удержанием (550мс) на его миниатюре в полоске — не даёт стереть последний оставшийся кадр анимации; движение мышью во время удержания отменяет удаление и переходит в обычный drag-реордер.
