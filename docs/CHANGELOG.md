# Changelog (unreleased)

- Refactor(sprites): убран множитель разрешения арта (`res`, `setSpriteRes`, поле "Res" в редакторе спрайтов) — был источником рассинхрона плотности пикселей героини/спрайтов с тайлами. Импорт картинки в кадр спрайта (`applySpriteImport`, `tile-edit.js`) больше не режет лист на кадры и не подгоняет картинку под текущий Size — импортированная картинка идёт как есть, её нативный размер становится Size (`fw`/`fh`) спрайта. Так любой спрайт, включая декоративные "тайлы"-объекты через привязанный sprite, может быть любого разрешения.
