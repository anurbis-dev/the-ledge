# Changelog (unreleased)

- Fix(entities): `tryMount` не трогал `p.facing` — рендер в маунте берёт направление у героини (`tryVehicleSprite` использует `p.facing`, не `v.facing`), поэтому транспорт при посадке мгновенно перещёлкивался на то, куда героиня смотрела при подходе, вместо того чтобы остаться в своей припаркованной ориентации. Теперь `tryMount` ставит `p.facing = v.facing` сразу при посадке.
- Fix(entities): `finishDismount` подтягивал `v.x/v.y/v.facing` к позиции героини на момент окончания unmount-анимации — транспорт визуально "ехал" вслед за игроком и перепарковывался там, где он спешился. Транспорт — не отдельная физическая сущность, пока герой за рулём (см. предыдущие правки), поэтому его x/y/facing не двигаются вообще: `finishDismount` теперь только возвращает `v.parked = true`, транспорт остаётся ровно там, где стоял изначально.
