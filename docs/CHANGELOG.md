# Changelog (unreleased)

- На старте игра теперь показывает простой титул с мягким проявлением, а по клику или клавише меню открывается плавно под ним.
- В редакторе спрайта добавлены отдельные анимации подбора для стойки, приседа и лёжа: `pick`, `pickCrouch`, `pickProne`.
- Главное меню и стартовый экран приведены к пиксельному стилю инвентаря: панели, заголовки и кнопки теперь держат тот же темный ретро-слой и рамки.
