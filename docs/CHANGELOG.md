# Changelog (unreleased)

- Feat(core,spriteset): добавлена новая запись каталога спрайтов `vehicle` (fw:24 fh:16, kind:'vehicle') с 9 слотами анимаций: idle (активный: едет), idleOff (припаркован, неактивный), move, jump, fall, land, attack, mount, unmount. Теперь Vehicle имеет реальный spriteId (раньше был null).
- Feat(core,objectset,editor): Vehicle изменил role с 'prop' на 'vehicle' (новая роль в ROLES). Добавлена система оверрайдов роли (Type) для всех builtin-объектов: `ledge.ed.objectRoles` localStorage. Type-селект в Object Details теперь работает и для встроенных объектов.
- Feat(render,entities): герой на маунте (p.mount truthy) больше не рисуется — вместо него кадры спрайта транспорта (tryVehicleSprite с маппингом state/phy → anim: idle/move/jump/fall/land/attack; 0.25s окно на mount/unmount). Припаркованные транспорты используют anim `idleOff` по умолчанию. При отсутствии спрайта — фиолетовая коробка-фоллбэк (drawMountFallback).
- Feat(core,editor): система оверрайда движения героини на уровень (hero-move.js). Новый модуль: `HERO_MOVE_KEYS` (~19 ключей: RUN, ACC, FRIC, WALK_V, CROUCH_V, PRONE_V, DASH_V, SLOPE_ALONG, GRAV, MAXFALL, JUMP, CUT, COYOTE, BUF, SLIDE_V, WJ_X/Y, WJ_LOCK, WJ_SAME_X/Y; исключает STEP_UP), `buildMoveOverrides()` собирает p.mv из LV.spawn.moveParams (diff-store, fallback на C). Player.js: p.mv устанавливается при спауне; step.js читает p.mv.KEY для movement. Редактор: плавающее окно `#edHeroMoveSettings` (Hero/Start → "Movement…" кнопка) с набором слайдеров; live-патч p.mv для feedback. Object-anchors.js: vehicle-специфичный hitbox {w:20,h:14}.
- Fix(editor): Sprite/Object Details — drag'n'drop PNG-файла из ОС в панель всегда писал в `animId`/`frameI` (то, что было выбрано последним кликом), а не в кадр под курсором — уронить арт прямо на превью кадра в другой анимации без предварительного клика по нему молча перезаписывало текущий выбранный (обычно idle). Дроп теперь хит-тестит позицию курсора через `hitDetailsDrop` и сначала переключается на нужный кадр.
- Fix(editor): `paintCanvas()` на каждый рендер подтягивал footprint (fw×fh) спрайта под буфер ТЕКУЩЕГО просматриваемого кадра (`bufW×bufH`) — для спрайтов с разным нативным размером арта в разных анимациях (например `vehicle`: `idle` нарисован, другие — нет/другого размера) переключение между кадрами тихо туда-обратно переписывало общий footprint и сбивало box/anchors всех остальных анимаций (рамка коллизии не совпадала с курсором). Ресайз footprint убран из paintCanvas — остался только по явному действию (импорт PNG / слайдер Size). Заодно `selectFrame()` перерисовывает canvas и после асинхронной загрузки буфера кадра, не только до неё.
