# Changelog (unreleased)

- Feat(enemies): AI patrol and chase — враги получают новую систему патруля и преследования. Каждый враг теперь имеет `points` (массив точек патруля x-координат), `pointPause` (пауза на каждую точку), `canChase` (включение режима атаки), `chaseV` (скорость погони, дефолт v×1.6), `sightFwd` (дальность зрения вперёд, 90px), `hearBack` (дальность слуха назад, 50px). AI state machine: `'patrol'` → `'pause'` → следующая точка (пинг-понг); при видимости игрока (вперёд в `sightFwd` или сзади в `hearBack`) → `'chase'` на `chaseV`; сброс chase в patrol при упоре в границу патруля/стену/обрыв или выходе игрока из видимости. Уровневый формат не сломан: 11-й элемент массива врага `aiCfg = {pts, pause, canChase, chaseV, sightFwd, hearBack}` (опциональный), пишется только при отличии от дефолта; существующие враги сериализуются как раньше. Редактор: новое окно Enemy AI (кнопка "⚙" в попапе лута) с контролями скорости/дальности видимости/слуха и списком точек патруля (+/− как у лифтов). Существующая механика (подпрыгивание, убийство прыжком, контактный урон/щит) не изменилась.
- Fix: `src/core/defaults.js` содержал 5 «висячих» `spriteId` (`s_9`/`s_10`/`s_11` на tiles 1/9/15/70 и tileGfx 9/15/27), не указывающих ни на один реальный `spriteDefs` (max был `s_8`). Т.к. `nextSpriteId()` считает свободные id только по реально существующим custom-спрайтам, любой новый спрайт получал именно этот номер и «оживлял» чужую висячую ссылку — новый спрайт внезапно оказывался привязан к произвольным builtin/custom тайлам. Убрал висячие `spriteId`; у всех пятерых уже была своя legacy-картинка (`src`), так что штатная boot-миграция (`migrateTilePicturesToSprites` в `migrate-graphics.js`) сама пересоздаёт валидный спрайт из неё при каждой загрузке — визуально ничего не изменилось, привязки больше не переиспользуются.
- Tag field for tiles, objects, sprites: `normalizeTile` / `normalizeObject` / `normalizeCustomDef` и exports `setSpriteTag()` поддерживают новое поле `tag` (текстовая метка). Custom tags пишутся в BAKED как часть item snapshot и undo/redo (как `name`); builtin tag overrides жмут в localStorage `ledge.ed.tileTags` / `ledge.ed.objectTags` / `ledge.ed.spriteTags` (dev-draft, не BAKED). Details panel: новое текстовое поле Tag под Name для всех трёх видов (Tiles, Objects, Sprites). Palette sorting: правая кнопка мыши на `#edbar` теперь содержит **Sort by Name** и **Sort by Tag** (взаимоисключающие тумблеры, персист `ledge.ed.palSort`); сортирует видимые сваши текущей вкладки после фильтра поиска; tag-mode: тэгированные впереди в алфавитном порядке, остальные в исходном.
