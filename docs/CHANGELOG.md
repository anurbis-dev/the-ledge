# Changelog (unreleased)

- Скосы: 2:1 (`SLR2`/`SLR3`, `SLL2`/`SLL3`), 4:1 (`SLR4A…D`) и дуги (`SLRCA`/`SLRCB`) стыкуются по высоте края — кочки и ямы без ступени 45°.
- Редактор: протяжка кисти скоса сама кладёт пологую цепочку; штрих вверх-вниз — дуга (кочка/яма).
- Ходьба по скосу: замедление от реального уклона, не всегда как 45°.
- Ходьба по скосу: вдоль склона ~90% бега (горизонтальный шаг /√2), иначе гипотенуза быстрее бега.
- Падение: средняя высота — залипание в приседе, большая — лёжа; сама встаёт, потом управление.
- Полная смерть (0 hp): пауза, затемнение, плашка «life capacity reached», тап/клавиша — в меню.
- Пыль при приземлении: масштаб от высоты падения (событие `landdust`).
- Удар головой о потолок в прыжке: крошка, глухой звук (`bonk`).
- Подводное снаряжение: акваланг (больше запас воздуха, авто-дозаправка запасным баллоном), баллоны с воздухом (подбираемый ресурс `S.bag.tank`), ласты (ускоряют плавание), гарпун (отдельный слот, стреляет в воде, стрелы подбираются обратно — `src/entities/harpoons.js`).
