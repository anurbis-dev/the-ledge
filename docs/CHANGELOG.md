# Changelog (unreleased)

- Feat(core,entities,editor,render): посадка в транспорт (mount/dismount) — новый плейсбл объект Vehicle, runtime-подмена скина игрока через `runtime.mountSkin` оверлей (не отдельная физическая сущность, физика игрока не меняется, меняются только spriteId/objectKind-скин и dmg/speedMul стат-оверрайды). Новый файл entities/vehicles.js (VEHICLE_DEF{dmg,speedMul}, mkVehicles, mkVehicleAt, packVehicle, nearestParkedVehicle, tryMount, tryDismount). Player: новые поля p.mount/p.mountSaved; damage() при hp≤0 форсит сброс маунта. Act/Space: если за рулём — высаживает (tryDismount), иначе если рядом запаркованный транспорт — сажает (tryMount, перед подбором предметов). Посадка недоступна с факелом. Редактор: новый тип 'vehicle' во всех точках интеграции (OBJ_KINDS, respawnObjectAt, edPlaceObject, edExportText, shiftAllObjects); новый файл editor/vehicle-settings.js с панелью (слайдеры Contact damage / Speed multiplier, копия структуры boulder-settings.js); #edVehicleSettings в index.html; плейсхолдер-иконка в editor/thumbs.js. Мир: LV.vehicles[] в blank-спеке; S.vehicles инициализируется в mkVehicles; mkWorld() сбрасывает runtime.mountSkin=null на каждый новый уровень (защита от утечки скина). Рендер: vehicles() в render/sprites.js рисует только запаркованные (v.parked); едущий скрыт. Persist: load/save vehicles по образцу boulders (не персистит transient parked). Комнаты: markList для room-fade.
- Feat(core,entities,editor,params): контактный урон-от-движения (contact damage) — новые параметры C.PLAYER_DMG (0) и C.CONTACT_DMG_RATE (2) в core/constants.js; новая группа PARAM_GROUPS 'mining' (Mining/Contact) в editor/params.js. Рефакторинг entities/mining.js: общий код breakTile/shakeTile для tryDig (кнопочное) и новой stepContactDamage (каждый кадр). stepContactDamage: гейт как tryDig (state==='normal' && onGround), эффективный урон = max(PLAYER_DMG, (p.mount && p.mount.dmg) || 0), таргет — стена впереди по ходу движения, списывает S.digHp на dmg × CONTACT_DMG_RATE × dt (консистентен с tryDig на одном тайле). Вызов в core/step.js сразу после stepDigShake. Блоки durability=0 не ломаются.
