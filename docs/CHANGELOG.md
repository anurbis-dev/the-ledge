# Changelog (unreleased)

- Fix(editor): импорт одиночной картинки в новый спрайт (`importSpriteFiles`, Sprites-таб, drag&drop) больше не режет её по умолчанию на грид 16×16 (`sliceSheet(img, name)` без `cellW/cellH`) — любая картинка крупнее одной ячейки (32×32, 48×48…) тихо превращалась в 4+ отдельных кадра-осколка вместо одного цельного спрайта. Теперь один файл = один спрайт нативного разрешения (`fw/fh` = размер картинки, клампится 8–128), без нарезки. Импорт тайлового листа (Tile-таб) не тронут — там нарезка по гриду 16×16 осталась целевым поведением.
