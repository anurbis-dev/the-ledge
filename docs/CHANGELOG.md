# Changelog (unreleased)

- Fix(gameplay): предыдущий фикс зеркалирования `weapon.rot` менял знак угла — верно только для арта, симметричного относительно оси кисти (напр. прямое древко факела), и неверно для любой асимметричной детали (несимметричный наконечник/обмотка и т.п.). `blitHeldSprite` (`render/sprites.js`) теперь делает настоящее горизонтальное зеркало: `ctx.scale(-1,1)` вокруг grip-точки при `facing<0`, **до** поворота на канонический (для facing>0) угол — так что «конец вверх» остаётся «концом вверх» и при зеркале, а наклон относительно персонажа зеркалится целиком, а не просто меняет знак. `hero.js`: `heroWeaponState` теперь отдаёт и `ang` (уже отражённый — для процедурного фоллбэка `drawHeldWeapon`), и `canonAng`/`mirror` (канонический угол + флаг «нужно ли зеркалить» — у харпуна `ang` уже настоящий мировой угол, зеркалить его нельзя).
