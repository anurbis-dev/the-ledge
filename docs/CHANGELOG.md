# Changelog (unreleased)

- Tag field for tiles, objects, sprites: `normalizeTile` / `normalizeObject` / `normalizeCustomDef` и exports `setSpriteTag()` поддерживают новое поле `tag` (текстовая метка). Custom tags пишутся в BAKED как часть item snapshot и undo/redo (как `name`); builtin tag overrides жмут в localStorage `ledge.ed.tileTags` / `ledge.ed.objectTags` / `ledge.ed.spriteTags` (dev-draft, не BAKED). Details panel: новое текстовое поле Tag под Name для всех трёх видов (Tiles, Objects, Sprites). Palette sorting: правая кнопка мыши на `#edbar` теперь содержит **Sort by Name** и **Sort by Tag** (взаимоисключающие тумблеры, персист `ledge.ed.palSort`); сортирует видимые сваши текущей вкладки после фильтра поиска; tag-mode: тэгированные впереди в алфавитном порядке, остальные в исходном.
