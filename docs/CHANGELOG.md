# Changelog (unreleased)

- Падение: средняя высота — залипание в приседе, большая — лёжа; сама встаёт, потом управление.
- Полная смерть (0 hp): пауза, затемнение, плашка «life capacity reached», тап/клавиша — в меню.
- На краю ↓: нажатие — присед → лёжа → вис; удержание — сразу в вис, кроме хода от края (лаз лёжа).
- Авто-подъём только после выхода из щели, не перед ней.
- Авто-запрыгивание на однотайловый уступ не из приседа и не лёжа.
